# 调试工具

整套正式比赛使用 `bash /root/工创/tools/start_competition.sh`，默认前台运行，按 Ctrl+C 统一退出，运行期间保持终端和 SSH 连接；
状态、日志、停止及雷达开关见[统一启动说明](../ros2_ws/src/agv_bringup/README.md)。
下列网页工具仍作为独立调试入口，不与正式比赛同时运行。

独立于正式比赛入口的专用工具：

- [全链路比赛调试网页](competition_debug/README.md)：独立端口8087，一键演练真实扫码、两轮原料/粗加工/暂存及最终停车入区；网页/显示屏本轮配置、三区域真实取放开关（默认开启，仅取放可替换为停留1秒）、地图/相机切换、停止释放确认和完整日志下载。复用现有执行逻辑，读取正式区域配置；不与其他控制入口同时运行。
- [路径规划与C板通信浏览器调试](route_debug/README.md)：真实底盘运动、自由行走、比赛路线演练。
- [原料区 / 粗加工区 / 暂存区网页调试](coarse_debug/README.md)：同页切换原料按色取料、粗加工三放三取、暂存首次圆环平放和第二次同色码垛；输入顺序与第一层布局，三区域真实驱动底盘/龙门架；原料仅抓取、粗加工仅取放、暂存仅放置/码垛用停车1秒模拟；暂存逐件高位对准后下降并实际恢复、最终收纳，无回P0；粗加工按实际长度/角度反馈取回，支持三区域独立参数编辑保存，默认端口8086。
- [主摄像头网页拍照](camera_capture/README.md)：网页实时预览，按空格或按钮将完整原图保存到板端，供数据集标注。
- [主摄像头圆环识别网页调试](ring_debug/README.md)：YOLO 每类最高分框、ROI 几何圆心、双色中心标注与实时帧率。
- [主摄像头物料识别网页调试](material_debug/README.md)：HSV 六色、YOLO 顶面/整体两种模型、多实例、框中心/圆心/最终中心与帧率，默认端口8085。

底盘调试工具与正式比赛不能同时控制底盘；拍照、圆环和物料识别工具运行时需关闭其他占用同一摄像头的程序。每个工具的启动、依赖和恢复步骤见对应说明。
