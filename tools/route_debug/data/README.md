# 行走记录

8080 页面打开“记录本次行走数据”后，每次点击开始生成一个 `route_日期_时间.jsonl`，按 50 ms（20 Hz）采样。停止、完成、故障或正常退出时追加摘要。数据流式写入，异常退出时已写入的行仍可读取；实际间隔以 `t_s` 为准。

页面提供最近 20 份记录的下载，目录内更早的记录仍保留，不自动删除。JSONL 每行一个 JSON 对象，可直接发给助手分析；记录文件不提交 Git。

- `metadata`：开始时间（北京时间）、采样间隔、单位、本轮设置及实际加载的导航参数。
- `settings` / `plan` / `event`：屏幕提交后的实际设置、规划结果、本轮状态变化、停止及 PID 无进展超时等事件。
- `sample`：实际采样时间、阶段、指令速度、实测位置/速度/yaw、反馈有效性与接收年龄、执行段和真实控制目标/误差。
- `summary`：最终状态、原因、时长和样本数。

`segment.error_x_m/error_y_m` 是以 `baseline_yaw_deg` 为方向的固定轴位置误差（m），与位置 PID 输入一致；`error_yaw_deg` 为连续角度误差（°）。仅在 `target_valid` 为真、反馈新鲜且执行段属于当前导航时用于判断收敛。指令角速度为 °/s，里程实测角速度 `wz_rad_s` 为 rad/s。记录为软件定时采样，不保证硬实时 50 ms。
