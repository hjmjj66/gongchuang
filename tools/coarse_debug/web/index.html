作业流程可选“1 秒模拟”或“真实执行”：前者仅以停车1秒替代取放并实际回工作位，后者发送所选区域的下位机取放程序并等待完成（包含程序自身的升降及回工作位）。底盘、伸缩、旋转、工作位和收纳均真实执行。原料底盘全程固定，每批首件记录唯一m0，前两件抓完返回m0时可被下一目标立即打断，第三件后直接收纳完成；粗加工和暂存第一次在入站纠偏后记录P0，收纳后返回P0，暂存第二次底盘全程锁定。追踪模式仅自动控制伸缩和旋转，手动取放按钮始终真实执行。关闭控制页或失联超过 8 秒会停止。
