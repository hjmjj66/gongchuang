## 已交付

## 实现相对计划的调整

网页实时连接使用 Python 标准库 HTTP + SSE 状态推送与应用心跳，替代原计划的轻量WebSocket服务库。浏览器控制请求仍使用HTTP，控制和计时在小车端处理；因此无需增加pip依赖或前端构建步骤。

规划器增加两项默认关闭的参数：`debug_allow_any_pose`、`debug_publish_progress`。前者允许工具初始化任意节点和朝向，后者输出10 Hz实际合并运动段快照；正式启动保留原启停区复位规则。新增消息 `RouteExecutionProgress` 仅用于显示。
