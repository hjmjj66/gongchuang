# 原料区两批按序取料方案

日期：2026-10-20。对应逻辑模块 `raw_task`，由共享主相机节点承载，比赛阶段为 s=4、s=10。

本次补充：主相机统一 1280×720；目标准心填写在 `profiles.raw_material.target_uv_px`，暂留 `null` 等待用户标定。当前颜色来自调度器保存的 `/qr/result` 解析数组；每个物料对准及停稳复核后，只向 `/C/arm_command` 发送一次 `0`，该程序包含抓取并入仓。完成反馈按用户要求先预留，接通后才根据相应反馈进入下一个颜色；当前未接反馈时不自动推进。

最新机械动作补充：用户已确认0程序在入仓、机构避让后由C板自动转到下一仓位，完成后反馈完整动作结束；三仓同向120°、第三次也转位的规则全部由C板实现。完整边界见[粗加工规格第3节](02_粗加工区放料与取回方案.md#3-采放后自动转仓动作契约)。上位机不额外发送转仓指令、不维护实际仓位、不添加转仓参数。

公共坐标、检测后端、速度单位、接口和停车约定见 [00_公共视觉与伺服约定.md](00_公共视觉与伺服约定.md)；三套源码完整对照见 [README.md](README.md)。

## 1. 任务范围与今年规则

两批复用同一流程，输入批次、物料序号和该次规定颜色。任务码第一组决定第一批颜色与顺序，第三组决定第二批颜色与顺序。颜色不能按去年红1、绿2、蓝3解释，今年固定红1、黄2、蓝3、绿4、黑5、浅蓝6。

命题第 4 页：转盘转向随机，约 6—10 秒一圈，停留次数与时间以现场为准，停止位置有误差。因此不能以固定转速、固定停止角度或固定抓取延时作为抓取依据。

命题第 7 页：一次抓一个，放到车上后才能抓下一个。视觉对准不能自动增加“已抓到”计数，也不能因当前色暂不可见而改抓其他颜色。

今日实现范围是指定色检测、停稳观察与底盘对准；以后由真实动作反馈确认抓取和入仓，再开始下一个物料。底盘行驶到该区域、工位朝向确认由外层完成。

整批输入为 `run_id/task_id/batch/colors[3]`，第一批取任务码第一组，第二批取第三组。检查长度为3、颜色合法且互异，两批颜色集合相同、顺序可不同；不自行排序。整批入口拟为 `/vision/raw/run_batch`，内部管理三次0和局部返回；纯 `/vision/raw/align` 只对准当前颜色，原料额外返回 `ready_to_grasp` 及其观测时间，不发送0。

单步带采料调试另用 `/vision/raw/execute_item`，需同时 `enable_motion=true`、`execute_action=true`，完成一件即停止，不假装完成整批或离站；只读观察与纯align均不发送机构指令。

0的取料高度由C板当前区域上下文决定：进站后先通过未来板间通信确认 `work_area=raw` 已同步，再允许发0。该机制由用户确认，见公共约定第7.3节。不能把粗加工的地面取回高度用于原料转盘。

## 2. 环节一：选中当前应抓的物料

### 进站观察位置：先让转盘大致居中

按用户补充，先将底盘停在原料转盘前方，使转盘中心大致位于相机画面中间，作为开始找料的观察位置。这个阶段只做粗观察，不要求每个物料都已处于抓取准心。

可先由路线粗停后人工调试验证视野；若实现自动居中，使用经范围和尺寸验证的转盘外缘圆等盘体特征估计中心，参考点及允许误差放YAML。不能用取掉部分物料后的剩余质心平均数代替盘中心。未可靠识别盘体时不盲目移动；盘体粗居中独立于当前颜色的精对准。

粗居中参数建议为 `raw_task.overview.target_disc_center_uv_px: [640.0, 360.0]`（实际准点可改）、`center_tolerance_px`、盘体ROI、外缘半径范围。转盘中心进入宽松误差范围后停车，再观察本次所需颜色。物料是否可抓取仍受机构可达范围约束。

首版默认 `auto_center_disc=false`，由路线粗停与调试确认视野，不把“必须完整检测盘缘”增加为启动条件。若启用自动粗居中，须另行提供盘缘检测、独立准心与B矩阵、速度限幅和范围验证；未实现时明确返回不支持，不能挪用物料准心。

确认观察位后记录当前入站的局部参考。每次成功取料后先由运动层返回这一观察位附近，停车后清空旧目标和判稳窗口，再寻找下一个颜色；避免底盘仍停在上一件的抓取位置，下一件已在视野之外。三件完成后也返回同一离站参考。局部返回复用粗加工第4节所需的二维位置反馈；缺失时完整批次在动作前报告 `LOCAL_RETURN_UNAVAILABLE`，不临时倒车计时。

观察位参考只对本次进站有效，第二批重新捕获，不能把随机摆放转盘的位置升级成全局地图原点。可作业ROI还应限制在停留时可抓取的前方扇区；目标在后方或只有越出车道才能对准时保持停车等待，不绕盘追料、不改抓别的颜色。

### 本项目推荐

先按任务码确定 `color_id`，在原料作业 ROI 内做该颜色 HSV 分割。对每个轮廓检查面积、宽高、是否截断、是否位于可作业区域；剔除车上物料和夹爪区域后再选择目标。

第一次获取时选择唯一符合条件的候选；多个候选无法区分时保留 `AMBIGUOUS`。连续观察时根据同一颜色、中心连续性和尺寸相近关联目标，不能每帧任意改选面积最大的区域。

首版中心采用轮廓质心。当前圆台物料近似垂直俯视时先验证质心能否满足对准精度；若中心受侧面或遮挡影响，再启用“HSV 候选 ROI 内局部霍夫顶面圆”的独立 profile。该圆应与物料掩膜相符、尺度正确且顶面边缘完整，不能把底部较大圆边缘当作顶面。

不强制在抓取前检测齐三个物料。主任务只要求正确识别当前颜色；同时观察其他物料可作为辅助，不构成无必要的三目标齐全门槛。

### 深度学习后续怎么接

模型提供当前颜色或“物料”候选，接同一套 ROI、身份和连续性筛选。六颜色分类模型直接给颜色；统一物料模型可在候选内部继续用 HSV 判色。检测框中心仅作为候选中心，精度需要时用顶面关键点、分割或局部几何法确定抓取参考点。停稳与伺服流程不因模型替换而取消。

## 3. 环节二：判断转盘上的目标是否停稳

### 去年方法与局限

江苏 `run_wukuaiyuanxin_1/2()` 将中心与某个参考中心比较，小于像素门槛便累计帧数，并对颜色历史投票；`run_wukuaiyuanxin_xuanzequyu()` 比较相邻中心并累计次数。思路可用，但部分丢失分支不清计数，因此不能直接把这些次数解释为连续稳定的新图像证据。

江苏另有固定位置 A1/A2 判色、第三色排除、位置序列与转向推断。它依赖旧三色及固定区域假设；其中部分分支排列相同，不能仅凭注释认定转向推断已正确。今日无需依赖该路径。

第三套使用机械臂跟踪后按抓取高度、误差等条件抓取，没有独立的转盘停稳检测；西安理工二维静态卡尔曼主要是平滑，也不能证明目标已经停止。

### 推荐判据

先令底盘归零并等待机械振动减弱。之后只对同一所需颜色目标的新鲜原始中心建立时间窗口：

```text
p_i = [u_i, v_i]
相邻位移 d_i = norm(p_i - p_(i-1))
窗口跨度 D = max(norm(p_i - p_j))，i、j 均在窗口内
```

判稳同时检查：底盘处于停车状态；有效新帧数量和观察时长足够；相邻位移不超过门槛；窗口总跨度不过大；目标颜色与关联身份一致。像素门槛、观察时长、新帧数量均由 YAML 配置。

时间窗口按采集时间排序，持续覆盖 `min_observation_time_s`，且其间不得有超过 `max_frame_gap_s` 的断档；实现用有界队列，并检查窗口内全部点的跨度，不能只检查首尾距离。只发送零速度并不等于已物理停车；完整流程还检查局部反馈的位移变化和yaw稳定，结合振动等待。未接运动反馈时只能在已知静止条件下独立验证视觉判稳，不据此宣称完整自动抓取就绪。

加入窗口总跨度是为了避免慢速物料每帧移动很少，却持续累计后被误认停稳。滤波后的平滑轨迹不作为唯一判稳输入。判稳仍是视觉近似判断，需要实测覆盖低速、转盘起停和模糊场景。

丢失、颜色/目标切换、采样间隔过大、底盘移动或图像过期时清除窗口和稳定计数。底盘跟随目标时，即使图像位置不变，也不允许输出“转盘已停”。

## 4. 环节三：对准与停稳复核

推荐流程：

```text
IDLE → CHECK_GOAL → WAIT_BASE_SETTLED → FIND_REQUIRED_COLOR
→ OBSERVE_TARGET_STABILITY → ALIGNING → ZERO_AND_SETTLE
→ VERIFY_ALIGNMENT_AND_STABILITY → ALIGNED
```

`ALIGNING` 使用公共限幅 P 控制，将当前物料中心对准 `raw_material` 专用准心。该准心是正确抓取关系在图像中的参考位置，不默认等于画面中心。

对准期间稳定计数无效。每个新帧检查目标关联和局部运动连续性；出现目标重新运动的可靠证据时归零并返回等待。对于无法区分“底盘造成的图像运动”和“转盘恢复转动”的情况，不宣称转盘停稳，最终必须在归零后重新观察。

`ZERO_AND_SETTLE` 后，用底盘静止期间的新图像再次验证：当前色仍正确、位置仍在误差阈值内、稳定窗口重新满足。若原料恢复运动，则返回观察；若对准误差不合格，按目标状态决定重新对准或等待。

可分别反馈 `aligned` 与 `ready_to_grasp`：前者仅表示视觉对准，后者还需底盘归零后的停稳复核。今日若未接机构，只返回视觉结果和抓取入口条件，不返回 `picked`。

发送0前再检查最新有效帧、当前颜色、可达性和ready时效，过期则撤销ready。视觉只能证明已经观察到的静止，不能预测转盘还会停多久；需要实测“停车复核＋通信响应＋夹爪接近”的总耗时能否落在现场停留窗口内。动作发出后目标恢复运动时，上位机只报告异常并保持底盘停止，不自行反向运动或补发0；中止能力须由C板动作契约明确。

## 5. 环节四：逐个取料的完整流程预留

接入动作后的每个物料流程：

```text
VALIDATE_BATCH_AND_DEPENDENCIES → WAIT_ROUTE_RELEASE
→ SYNC_RAW_CONTEXT → CONFIRM_OVERVIEW → CAPTURE_LOCAL_REFERENCE
→ 选择当前颜色 → 停稳观察 → 对准 → 停车后再次停稳复核
→ 检查ready仍有效 → 停止视觉输出 → 发一次0 → 等待真实完成反馈
→ 提交本物料完成状态 → RETURN_OBSERVATION → 停车并清窗口
→ 下一物料；第三次后返回离站参考 → COMPLETED
```

每批循环三次；两批只更换颜色序列与批次身份。动作遮挡图像时不重新发伺服速度；动作结果未知时保留当前步骤，不当作抓空，也不重复抓取。

西安理工用三个中心平均估计料盘中心，可作为可视化和视野检查的参考；它不能代替当前物料中心。随机摆放的料盘也不能作为固定地图节点原点。

完整区域作业结束后，需恢复本次记录的局部离站参考并停车，再交给路线执行。原料区不能简单“对准随机转盘中心即回中”；所需局部位置能力仍待实现，独立对准测试不伪造回中成功。准心、停稳窗口、区域同步、动作反馈和局部返回只检查本次启用功能；缺依赖在批次开始即报告，不执行半批后再报错。

## 7. 调试与验收场景

1. 只识别：给定六色中任一颜色，仅该目标被选中；其他色更近、更大也不改变任务。
2. 候选干扰：车上同色物料、夹爪、转盘边缘、阴影进入画面时，目标身份不被无条件替换。
3. 动静切换：转盘持续转动时不得判稳；停留后可判稳；再次转动后清除判稳。
4. 帧新鲜度：冻结同一图像或中断采集，不累计新帧证据、不报告停稳成功。
5. 底盘闭环：两轴误差方向正确，达到阈值归零，停止后重新复核。
6. 两批任务：使用不同顺序连续调用，新的颜色清除旧目标与窗口。
7. 完整动作接入以后：只有抓取并入仓确认才推进物料序号；三物料完成及离站参考恢复才结束区域作业。
8. 每件取料后返回本次观察位，下一颜色从新画面重新获取；第二批不用第一批的局部坐标。
9. 0发出前ready过期或转盘重启则撤销许可；已发0后不自动重发，原料区域上下文未确认不执行。
10. 目标在不可达后侧、需驶离车道才能对准时保持等待，判稳不等于可抓取。

规则规定运行总时长及停止运行判定，等待转盘有额外时间约定；模块应记录等待原因和时长。沿用总体规划，等待不自动变成成功，不默认超时跳过颜色；后续依据实测设计自主恢复。
