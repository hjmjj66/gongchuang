# 车体坐标统一实施记录

日期：2026-10-26。用户现场确认并逐项同意统一全链路：C 板控制输入、原始位置和实测速度均采用 x 前 / y 左，yaw 逆时针为正。

## 当前约定

| 量 | 正方向 |
| --- | --- |
| `vx_mps`、串口 vx | 当前车头前方 |
| `vy_mps`、串口 vy | 当前车身左侧 |
| `omega_deg_s`、串口 wz、yaw | 逆时针；ROS 输入 °/s，串口 wz 和反馈 rad/s |
| `move --dx` | 本次起步时的前方；负数后退 |
| `move --dy` | 本次起步时的左方；负数右移 |
| `/C/odometry.x_m/y_m` | 会话建立时的前/左固定轴，车辆转向后轴不随车转 |

节点 1→2、车头朝地图下方、未启用终点对齐时，前进段必须下发 `vx>0, vy=0, omega=0`。地图朝向由页面所选车头方向和里程 yaw 变化共同确定。

## 修正内容

原先规划器将前进映射到 vy，因而实际向左运动。现在前后用 ±vx、左右用 ±vy。桥接继续按 vx、vy、wz 的原顺序编码，不交换、不取反；消息字段、协议字节布局和 CRC 保持原定义。

车体系转固定系采用标准逆时针旋转：

```text
dx_fixed = cos(yaw)*dx_body - sin(yaw)*dy_body
dy_fixed = sin(yaw)*dx_body + cos(yaw)*dy_body
```

板端原始位置相对原点 `(x0,y0,yaw0)` 的会话变换、定距测试和地图锚点使用相应逆变换：

```text
dx = x_raw-x0
dy = y_raw-y0
x_local = cos(yaw0)*dx + sin(yaw0)*dy
y_local = -sin(yaw0)*dx + cos(yaw0)*dy
yaw_local = yaw_raw-yaw0
```

例如会话 yaw=90° 时，沿当前车头前进应增加固定 y。原点 yaw0=90° 时，板端固定 y 正向位移应投影为会话 x 正向。

规划器、里程适配、手动 CLI、网页轨迹与标签、接口注释、协议和现行指南同步更新。早期设计文档顶部标明历史状态，旧交换轴表不得用于当前代码。用户的规划速度、容差和打滑告警策略沿用现有配置。
