# 暂存区龙门架实施记录

日期：2026-11-15（已更新高位直接放置与首次离站补偿）。依据：[已确认指导计划](14_暂存区龙门架视觉伺服改造指导计划.md)。正式阶段8/14及8086网页已接入。本记录的软件验收不代表真实机械动作表或现场精度已经验证。运行入口见[STORAGE.md](../../ros2_ws/src/agv_perception/STORAGE.md)、[网页工具说明](../../tools/coarse_debug/README.md)。

## 实现行为

第一次：WORK(3)高位 → 最多3秒水平纠偏 → 底盘高位环2校准并停车 → 锁定底盘 → 按位置顺序逐件高位伸缩/旋转视觉对准、4张新帧达标、停流交接、直接第一层放置(6) → 第三件后INIT(2)收纳完成 → 沿车体正vx补偿camera_car_offset（79.45mm） → 确认停车。每次放置程序自动回统一高位，无上位机预下降。没有取回、二维返回或末次角度纠偏。

第二次：底盘全程零速 → WORK(3) → 机构有限旋转补齐三色 → 实际WORK(3)恢复 → 按第二批颜色逐件对准当前同色物料、4帧判定、高位直接叠放(7)并由程序回高位 → 收纳(2)。不纠偏，不做底盘校准或搜索。例 `156+123+516+231` 对应码垛颜色5→1→6、记录位置2→1→3；不采用第四组231。

- 图像误差 `eu=u-u_ref, ev=v-v_ref`，机构 `yaw_wz=-PID(eu), fb_rpm=-PID(ev)`，单位rad/s和RPM，视觉升降0；两次共用准心、机构PID、四帧门槛、高位工作姿态。
- 四帧使用正常限幅输出判断，两轴输出及欧氏像素误差都达标才交接固定放置。重复帧不计数，缺目标清计数；固定动作后不使用之前姿态的图像。
- 三色每色默认连续3张新帧确认，可跨视野累计颜色；不保存跨姿态像素地图。扫描以WORK姿态为方向参考，左右位置各有限探索一次，50Hz控制循环约束搜索时段，不在任意姿态按编号大小决定方向。
- 初次寻找仅有限探索；已经跟踪过再丢失则两轴立即零速，原地等待。一张有效新帧重现即可恢复。健康缺目标无业务总超时；真实图像断流、许可、反馈和动作故障仍停止报错。
- 视觉等待保留同一机构流，持续发送全零速度。这样不在短帧暂停后重开新流，避免旧流未收到停止时拒绝新流并触发看门狗；四帧达标后关闭流，由桥接确认零JOG及新鲜idle后接入固定放置。扫描恢复WORK、取消和退出同样复用交接及ABORT，不复播旧速度。

## 公共宿主与调度

`StorageTask`复用粗加工的低层PID、斜率、底盘环2校准和机构四帧门槛，暂存四帧合格后直接PLACE或STACK；首次收纳后复用粗加工的EXIT_OFFSET里程闭环。粗加工保留其高位六步取放及两次离站补偿；原料业务流程保持原约定。公共配置校验复用共同机构字段，暂存不保留 `gantry_return` 或 `xy_return`。

正式宿主已对storage启用连续机构发布、固定动作和停止清理。storage与raw采用桥接管理连续流/动作交接，避免在上位机等旧idle时卡住请求。桥接及更新版协议字段沿用现有实现，`RunWorkBatch.action`的距离字段统一改名为camera_car_offset，并从源接口重新生成构建。

暂存报告 `reference_restored=false, final_alignment_outcome=NOT_RUN`，不伪造二维返回。mission在8/14阶段以三步、首批映射、全部完成、控制释放、机构空闲及可行驶验收。执行端仅在最终收纳完成、首次离站补偿并停车、底盘零速且连续流已释放后报告可行驶。其他区域参考位验收保持各自规则。

## 网页与配置

8086继续同页切换原料/粗加工/暂存。暂存第一次输入123排列，第二次输入三个不同颜色及按环1/2/3的布局，第一层由人工摆放。

网页实际执行WORK、搜索、r/t伺服、逐件恢复WORK、最终INIT及首次离站补偿；只将PLACE/STACK替换为全轴零速至少1秒，绝不发送6/7。第三件也先实际回高位，再收纳。首次固定动作序列为 `[3,3,3,3,2]`，第二次为 `[3,3,3,3,3,2]`（多一次扫描后恢复）；两次机构JOG的升降轴均为0。

页面增加实际机构运动说明、底盘锁定、机构请求/动作状态、扫描颜色、当前误差/中心/帧信息、旋转rad/s、伸缩RPM、四帧计数及等待原因。暂存删除P0返回/取回位置表，底盘坐标只供诊断。参数独立保存storage，运行时禁止保存或切换；页面失联默认8秒停止底盘、机构及ABORT，不自动续跑。

正式 `storage.yaml`保留待标定null；独立网页YAML提供可编辑低速初值，删除旧双平移伺服/码垛独立准心、二维返回、旧缺目标业务超时等参数。网页保存不修改raw/coarse或正式比赛参数。
