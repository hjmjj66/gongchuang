# 主相机简明执行流程

日期：2026-10-20。本文说明拟实现流程；当前没有新建主相机节点或修改扫码程序。

## 1. 几个部分各管什么

- 扫码节点：输出 `/qr/result` 的二维码文本。
- 比赛调度：保存任务数组，向当前区域提交一次整批任务，保存已确认步骤并等待区域结果；不再并行发送同一步采放命令。
- 一个主相机视觉节点：统一 1280×720，内部有原料、粗加工、暂存三个任务；识别当前目标，用底盘将它对准 YAML 中的准心。
- 后续板间通信节点：转发底盘速度与采放请求，返回下位机执行结果。
- 下位机：执行封装的采(0)、平放(1)、码垛(2)程序。0包含抓取并入仓，1和2包含出仓及对应高度的放置；动作成功、机构避让后内部自动转到下一仓位，就位后才反馈完成。全部机构与转仓由C板处理。

每次进站，板间通信先同步当前区域并确认C板已就绪。原料和粗加工虽然都发0，C板按区域分别选择转盘取料或地面取回高度，不增加动作编号。

区域间行驶沿用已有路线规划，不由这三个视觉任务负责。

## 2. 需要用到的话题

| 话题 | 内容 | 使用方式 |
|---|---|---|
| `/qr/result` | 例如 `156+123+516+231` | 读取一次，校验并保存本轮任务；文字结果拟保留最近值供晚加入订阅者读取 |
| `/C/controll` | 连续底盘速度 | 对准时持续输出；对准完成先发零速度 |
| `/C/arm_command`（拟新增） | `UInt8`：0 采，1 平放，2 码垛 | 一次目标只发送一次，不能逐帧重复发送，也不缓存历史命令给晚加入订阅者 |
| `/C/arm_status`（拟预留） | 对应采放程序的执行结果 | 完成后才允许当前步骤结束；具体格式待约定 |

现有扫码程序无目标时不发空字符串。拟补充的是文字结果的最近值缓存；调度同时保存自己的本轮任务，离开扫码区不会丢失数组。最近值缓存只在发布节点存活期间有效，旧二维码中心点不作控制依据。新一轮显式更新任务身份与任务数据。

## 3. 扫码后保存哪些数组

对 `156+123+516+231` 保存：

```text
第一批颜色：[1, 5, 6] → 红、黑、浅蓝
第一批位置：[1, 2, 3] → 粗加工和首批暂存都用它
第二批颜色：[5, 1, 6] → 黑、红、浅蓝
第二批粗加工位置：[2, 3, 1]
第一层暂存映射：红→1，黑→2，浅蓝→3
```

当前物料完成后，才把数组索引加一；不是检测到下一种颜色就加一。

## 4. 原料区怎么取

每次只处理数组中当前颜色：

先在转盘前方停车，让盘中心大致居于画面中间，再进入下列指定色流程；粗观察居中和抓取准心分别配置。

```text
找该颜色的 HSV 物料轮廓 → 求质心 → 停车观察转盘目标停稳
→ 移动底盘，让质心对准 raw_material 的准心
→ 归零，再确认物料稳定、误差合格
→ ready未过期时发送一次0 → 等待完整程序完成
→ 返回本次观察位附近并停车 → 清空旧目标与稳定窗口 → 下一个颜色
```

第一批重复红、黑、浅蓝；第二批重复黑、红、浅蓝。准心在 YAML 的 `profiles.raw_material.target_uv_px`，由用户以后标定。

盘体自动居中是可选功能，首版不要求完整盘缘可见。只处理安全可达范围内的当前颜色，后方不可达时等待转盘；三件完成后恢复本次局部离站参考。

## 5. 粗加工怎么放

首次看到三个工位，用霍夫圆得到各组圆心，按左到右赋 1、2、3；当前不读圆内数字。

第一批：找1号环 → 对准 → 发1并等完成；找2号环 → 对准 → 发1并等完成；找3号环 → 对准 → 发1并等完成。

第二批位置改为2、3、1，颜色按第二批顺序。所有对准都用 `profiles.coarse_ring.target_uv_px`。

放一个后圆环会被物料遮挡，但该工位的编号不改变。下一次只识别当前要放的空圆环；已建立工位身份后，不把剩余圆环重新编号。底盘移动后用当前新帧更新圆心，不拿旧像素直接控制。无法确认身份时停车重新获取。

每项采放与转仓完成后，通过局部位置接口返回中心观察位附近，停车并用新画面复核布局再找下一目标。这个返回需要二维位置或固定参考，当前只有累计路程标量的反馈不足以代替它。

## 6. 粗加工怎么取回

三个全部放完，才按当前批次颜色顺序取回：

```text
找当前颜色物料 → 用 HSV 掩膜轮廓质心定位
→ 对准 coarse_material 的准心 → 停车
→ 发一次 0 → 等采料程序完成 → 下一颜色
```

取回用的是物料中心，圆环被挡住也可以进行。它与放料圆环准心分开标定，不复用放料时的旧像素坐标。全部取回、入仓、转位完成后，返回观察范围，必须再用三个空圆环做离站精校准：vx、vy将三圆心平均点对准YAML指定像素，omega使拟合直线接近水平（默认参考角0°，可标定修正）；中心和角度同时合格、停车后新帧复核通过才去暂存区。详见[粗加工详细规格](02_粗加工区放料与取回方案.md)。

## 7. 暂存只记住两个模式

第一批：和粗加工放料类似，按第一批位置找圆环，对准后发1，等完成，再处理下一个。记录颜色与位置关系。

第二批：按第二批颜色找第一层同颜色物料，对准其中心后发2，等完整码垛动作完成，再处理下一个。示例中黑、红、浅蓝对应位置2、1、3。先用 HSV 质心验证闭环，精度不足再评估顶面圆心；码垛的准心单独标定。

第二次进站先在观察位重获三件第一层物料，核对颜色排列与第一批记录，建立本次参考，再逐件对准；不能复用第一批旧像素。暂存每次放置后同样局部返回，放满后用局部位置恢复离站参考，不要求看见三个空环。

当前1表示完整出仓并平放，2表示完整出仓并码垛，C板按指令选择分别标定的高度。接触后停止下降需要实际传感反馈，暂不作为动作实现前提，见暂存详细方案。

## 8. 每一步都遵循同一个顺序

> 校验整批依赖并同步区域 → 取出当前目标 → 看清目标 → 连续新帧对准 → 停车后复核 → 发一次0/1/2 → 等完整结果 → 局部返回 → 下一项。

完成反馈按用户要求先预留，暂不实现板间通信。还没收到动作完成时，不因再次检测到误差合格而重发动作，也不开始下一物料。三个区域的局部返回能力仍待实现；粗加工还必须执行最终三空环精校准，原料和暂存恢复各自本次观察位的局部离站参考。单点伺服omega=0不代表锁定车头，需监视yaw漂移；所有底盘纠偏都受车道内工作范围约束。
