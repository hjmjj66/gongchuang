## 已完成

- 新增 `coarse_node` 和无 ROS 依赖的 `CoarseTask`：高位直线斜率 PID、定时下降后记录参考位置、按本批数组三放并记录位置、按相同顺序二维返回后用物料工具宽容差三取、返回参考位置、高位复校准、独立收纳。
- 平移按工具原图坐标映射为 `vx=-PID(u-u_ref)`、`vy=+PID(v-v_ref)`；两次角度纠偏使用圆心直线斜率，不追踪绝对 yaw。二维返回只将当前 yaw 用于固定系到车体系速度转换。
- 两次角度校准各最多 5 秒，等待图像、纠偏和停车复核均计入；超时停止角速度后继续。普通步骤异常停止、报错，不自动重试。
- 圆环、物料使用单份相机采集和识别工作线程，共用兼容运行库，两个模型初始化后复用；任务开始才打开相机，结束释放。现有独立识别工具保持可用。
- 在现有 C 板串口中接入 ARM_CMD、ARM_JOG 和 ACK，新增 `ArmCommand.srv`、`JogArm.srv`、`ArmExecution.msg`；底盘串口周期及最终速度出口不变。
- 固定动作仅发送一次，ACK 只代表受理，确认忙态回 idle 后推进。定时下降从实际串口发送开始计时，到时显式发送 JOG 零速停止保持。
- 停止请求明确发送中止；下降时先清零 JOG。运行状态核对当前请求 ID，避免用此前的 idle 宣布新请求已静止。
- 比赛调度阶段 6、12 接收区域控制速度，验证身份与许可后转发。`RunWorkBatch.Result` 新增 `final_alignment_outcome`；最终超时跳过可结束粗加工，但不伪造角度达标或放宽其他区域的归位条件。
- 增加业务 YAML、launch 入口、运行日志和[使用/标定说明](../../ros2_ws/src/agv_perception/COARSE.md)。
- 增加[独立网页调试工具](../../tools/coarse_debug/README.md)，默认8086。人工固定机械臂/相机，输入圆环顺序，首尾斜率纠偏，三放复用圆环视觉伺服并记录位置，三取按原顺序只做二维返回；六次动作各停车1秒，不发机构指令。独立 YAML 已填保守小值，页面支持停止后编辑保存、下一次开始生效。

## 现场剩余工作

1. 按电控动作表修改 YAML 的工作位、放、取、收纳动作号，目前占位 2/3/4/5。
2. 确认下位机支持下降 JOG 后直接执行固定动作，且每次取放结束恢复同一低位观察姿态；若仍返回基准无效，上位机报错停止，不自动插入 HOME。
3. 填写下降 RPM/秒数、共同准心、PID、限速、像素与位置容差。未实测的参数仍为 `null`，运行端报告配置未就绪并拒绝运动。
4. 接入相机验证高位/低位实际视野、完整实时识别控制链路，以及最后高位复校准再收纳的姿态顺序。
5. 依指导方案逐段进行两批实车取放与离站验收；当前软件结果不替代这些验收。

本次未改写现行机械臂协议、外部部署权重或电控代码，也没有添加其他区域的占位成功实现。
