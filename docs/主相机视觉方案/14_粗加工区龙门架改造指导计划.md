日期：2026-11-15。状态：需求已确认，正式流程与8086调试已按本计划实施并完成软件验收，见[实施记录](15_粗加工区龙门架实施记录.md)。实车标定与电控联调待完成。

本计划依据本次会话的最终确认和[通信协议 v0.5](<../../上位机通信协议(更新版)>)。它更新[旧粗加工指导](06_粗加工区任务流程与实施指导.md)中底盘逐环对准、记录底盘位置取回、取回时物料视觉纠偏、最终底盘二维返回和每次5秒纠偏的规定。旧实现记录不能作为本次龙门架改造的验收依据。

本计划编写时工作区已有部分实现草稿；用户随后授权开始修改，现已补齐控制器、网页、配套测试和说明。以下作为最终实现规格保留，软件验收不代表可直接使用未标定参数进行实车任务。

## 1. 范围与最终约定

- 正式粗加工在比赛阶段6、12各执行一次；两批复用同一流程，每批独立记录位置，不沿用上一批数据。
- 保持现有任务接口 `/vision/coarse/run_batch` 和公共视觉宿主；更新现有8086网页的粗加工选项，不新增独立网页。
- 初始水平校准、初始对准2号环及最终水平校准由底盘完成。逐件放置、逐件反馈返回由龙门架伸缩和旋转完成。
- 相机与末端固定，随机构一起运动。高位工作位置与行驶收拢位置是两个不同姿态。
- 任务顺序完全按输入，例如213：先放2、1、3，再取2、1、3。取回无需额外加工等待，返回首件的行程充当等待时间。
- 圆环编号和最终圆心直接使用已有圆环工具；优先几何圆心，允许工具明确标记的框中心估计。
- 初始2号环对准和逐环放置共用同一个像素标定点；为空时用实际原图中心。
- 放置用图像误差速度闭环；取回用实际 `fb_mm` 和机构连续 `yaw_rad` 反馈闭环，不使用物料模型纠偏。
- 每件固定取放程序完成后，机构自动回到以2号环为中心的统一高位工作位置。固定程序负责相应托盘动作，上位机不另拆托盘控制。
- 三件取回完成后，先恢复高位工作位置，再水平纠偏，再执行收拢，之后沿车体正vx闭环移动79.45mm并确认停车，再交回下一比赛阶段。
- 两次水平纠偏各最多3秒，超时记录跳过并继续。正常图像下目标不可见则等待；通信、图像流或机构执行异常则停止报错。

## 2. 新通信协议及动作号

### 2.1 正式动作映射

以下采用 v0.5 的正式编号，替代旧文档和代码草稿中的占位编号。

| cmd | 协议名称 | 用途 |
|---|---|---|
| 0 | STOP/ABORT | 中止当前机构动作并保持；不是收拢 |
| 1 | HOME | 回零/故障恢复入口；正常粗加工流程不自动插入 |
| 2 | INIT | 回到初始收拢状态，对应 `stow_cmd` |
| 3 | WORK | 伸到工作位置，对应 `work_pose_cmd` |
| 4 | PICK_RAW | 原料区夹取，对应原料区取料配置 |
| 5 | PICK_ROUGH | 粗加工夹取，对应 `pick_cmd` |
| 6 | PLACE_TEMP_1 | 暂存区第一层放置 |
| 7 | PLACE_TEMP_2 | 暂存区第二层叠放 |
| 8 | PLACE_ROUGH | 粗加工放置，对应 `place_cmd` |

粗加工配置最终应为：`work_pose_cmd=3`、`place_cmd=8`、`pick_cmd=5`、`stow_cmd=2`。0、1不能用作普通工作动作，9～15目前保留，不能当作已定义动作使用。

这些映射已同步用于正式配置、8086独立调试配置和相关测试；后续调整仍需同步核对示例和说明文档，避免只改一份YAML。原料与暂存只同步协议映射及相关测试，不借此改变其业务流程。

### 2.2 已重新确认的两项协议文字差异

用户阅读本轮核对问题后，再次确认：

1. 当前目标固件支持JOG之后直接执行固定动作，无需额外HOME。新版协议中“基准失效、先HOME”的段落尚未同步，不在正常流程中插入HOME。
2. 本次联调的 `fb_mm`、机构 `yaw_rad` 是真实反馈。新版协议中“位置层落地前上报指令位置”的段落尚未同步，取回按实际反馈闭环设计。

上述是用户对目标固件的明确约定，不是本轮实测结果。保留原协议文件原文；后续协议说明需注明本项目适用条件，不能把指令积分值包装成实测位置，也不能改动线上字段或单位。

### 2.3 发送与完成语义

- 固定动作通过 `0x02 ARM_CMD` 只发送动作号；动作内部抓放高度、托盘交换和运动时序由下位机负责。
- ACK只表示受理或拒绝，完成需等待本次动作对应的执行反馈，确认忙态结束回到idle；error、拒绝、超时或结果未知均停止报错，不自动重复取放。
- `0x03 ARM_JOG` 按50Hz发送：旋转rad/s，逆时针正；伸缩RPM，伸出正；上下RPM，上升正。旋转和伸缩允许同时运动。
- 连续JOG切换固定动作：清除旧速度、发停止保持、确认机构空闲，再提交固定动作。固定动作期间不继续发送旧非零JOG。
- 协议没有“发送目标长度和目标角度”的绝对位置帧。记录点返回由上位机根据实际反馈计算速度，再发送现有JOG实现。
- 按最新要求，粗加工不再额外定时下降；环2校准、逐环视觉对准和反馈取回均从WORK工作位置进行，固定取放程序自身的高度动作由下位机处理。

## 3. 每批完整流程

```text
到达粗加工区并停车
  → WORK(3)，等待到达高位工作位置
  → 底盘按圆心拟合直线水平纠偏，最多3秒
  → 保持高位，底盘视觉对准2号环与共同准心
  → 底盘停车；可记录P0=(x0,y0)作调试观测
  → 对输入顺序中的每一件：
      保持WORK工作位 → 旋转/伸缩视觉对准对应圆环
      → 连续4张新帧满足像素及两轴输出门槛
      → 两轴停止，记录本件实际伸出长度和机构角度
      → PLACE_ROUGH(8)，等待放置及自动回高位完成
  → 对相同输入顺序中的每一件：
      保持底盘停止，在高位用实际反馈返回记录的长度/角度
      → 停止并复核到位 → PICK_ROUGH(5)
      → 等待夹取、入仓及自动回高位完成
  → WORK(3)，确认处于标准高位工作位置
  → 底盘按圆心拟合直线水平纠偏，最多3秒
  → INIT(2)，等待收拢完成
  → EXIT_OFFSET：沿车体正vx移动mission.yaml配置的79.45mm，里程闭环到位并确认停车
  → 本批完成，释放控制权，由比赛状态机进入下一阶段
```

初始对准2号环和每件圆环视觉对准均在工作位进行，每件放置后恢复工作位后直接对准下一环，不插入额外下降。固定 `PLACE_ROUGH/PICK_ROUGH` 负责程序自身的升降。

取回使用放置时记录的伸缩/旋转位置；升降位置不参与这个二维机构目标。取回前保持高位，取料程序自己处理下降高度。

初始2号环校准结束后，不再进行底盘平移。最后也不执行旧版“回P0”的底盘二维闭环；最终底盘只允许为水平纠偏产生角速度。

### 3.1 建议状态划分

| 状态 | 控制内容 | 正常转移条件 |
|---|---|---|
| WORK_ENTRY | 固定高位动作 | WORK完成 |
| ALIGN_ENTRY | 底盘斜率纠偏 | 达标或3秒超时 |
| CENTER_RING2 | 高位底盘对准2号环 | 新帧误差达标且底盘停止 |
| ALIGN_RING | 本件机构视觉伺服 | 连续4张新帧达标 |
| STOP_PLACE | 机构归零、记录实际位置 | 停止交接完成且收到新反馈 |
| PLACE | 固定粗加工放置 | 本件放置及回高位完成 |
| RETURN_ITEM | 本件实际长度/角度闭环 | 两维误差进入容差 |
| STOP_PICK | 停止及位置复核 | 停止后仍在两维容差内 |
| PICK | 固定粗加工夹取 | 本件夹取及回高位完成 |
| WORK_EXIT | 恢复标准高位 | WORK完成 |
| ALIGN_EXIT | 底盘斜率纠偏 | 达标或3秒超时 |
| STOW | 固定收拢动作 | INIT完成 |
| EXIT_OFFSET | 收拢后沿车体正vx移动偏置距离 | 里程到位、新鲜低速反馈和停车等待达标 |
| DONE / ERROR / STOPPED | 完成、故障或人工停止 | 不自动重启 |

PLACE之后尚有未放物料则回ALIGN_RING；第三件放完转RETURN_ITEM。PICK之后尚有未取物料则回RETURN_ITEM；第三件取完转WORK_EXIT。

## 4. 三种闭环与坐标方向

### 4.1 水平纠偏

用圆环工具同一张新帧中的有效中心拟合直线 `v=k*u+b`，至少两个圆心且横向跨度有效。目标为斜率0；有三个中心时使用全部有效点。

图像坐标采用工具原坐标：左上原点，u向右、v向下。右侧3号环偏高时k为负，因此使用 `wz=PID_angle(-k)` 给出正角速度，符合用户指定方向。底盘 `vx=vy=0`，机构两轴停止。

不用当前底盘yaw去追踪0°、90°等绝对目标。不足两个中心时停车等待，仍受本次3秒上限约束。达标判据使用斜率容差和新帧确认；超时结果记为 `TIMEOUT_SKIPPED`，不能记作 `ALIGNED`。

### 4.2 高位2号环的底盘校准

设共同准心为Q，当前2号环中心为C：

```text
e_u = C.u - Q.u
e_v = C.v - Q.v
vx = -PID_base_u(e_u)
vy = +PID_base_v(e_v)
wz = 0
```

映射沿用本项目已经确认的相机/底盘关系。底盘准心误差用欧氏距离判定，并结合新帧确认、底盘低速及停止交接。2号环暂时不可见时零速等待，不自动改用1号或3号完成这一步。

### 4.3 放置时的机构视觉伺服

```text
e_u = C.u - Q.u
e_v = C.v - Q.v
yaw_wz = -PID_gantry_u(e_u)
fb_rpm = -PID_gantry_v(e_v)
ud_rpm = 0
底盘 vx = vy = wz = 0
```

目标偏左时逆时针转动，目标偏上时伸出。这里的r/t表示机构伸缩与旋转自由度；视觉对准阶段采用像素误差控制速度，不要求从像素反解绝对极坐标。

连续4张不同的新采集帧需同时满足：

```text
hypot(e_u,e_v) <= tolerance_px
abs(yaw_wz) <= small_yaw_rad_s
abs(fb_rpm) <= small_fb_rpm
```

检查本帧正常计算并限幅后的输出；不能先置零再用零输出通过门槛。无新帧不增加计数，目标丢失或不达标清计数。停止后的记录取自新鲜实际反馈，发生在固定放置之前，避免记录到放料后自动返回高位的位置。

### 4.4 取回时的机构反馈闭环

对当前顺序的记录 `(r_i,t_i)`：

```text
e_r = r_i - STATUS.fb_mm
e_t = t_i - STATUS.yaw_rad
fb_rpm = PID_return_r(e_r)
yaw_wz = PID_return_t(e_t)
ud_rpm = 0
底盘 vx = vy = wz = 0
```

长度误差按mm判断，角度误差按rad判断，两者分别进入配置容差后停止；停止后用新反馈复核，偏出则继续本件返回，不重置该次返回总计时。连续角直接相减，不按±π折返到另一圈。

反馈用于上位机闭环，不把一次速度乘时间视为返回完成。不识别物料、不重新对圆环、不改变已记录目标。

## 5. 找目标、等待与异常

| 情况 | 行为 |
|---|---|
| 水平纠偏有效点不足 | 底盘停止等待；3秒到则跳过本次纠偏 |
| 高位2号环不可见 | 底盘和机构停止，继续等待 |
| 放置找1号环 | 机构小幅向左、逆时针探索 |
| 放置找3号环 | 机构小幅向右、顺时针探索 |
| 放置找2号环 | 停止等待 |
| 探索后仍不可见 | 停止并持续等待，不跳件、不宣布对准 |
| 正常图像下目标暂时丢失 | 停止视觉伺服、清达标计数；出现新目标帧后继续 |
| 图像流中断、实际反馈超期、控制许可丢失 | 停止报错，不能作为正常等目标处理 |
| 动作拒绝、错误或返回超时 | 停止报错，不自动重试取放 |
| 人工停止或网页失联 | 停止底盘和机构，结束本次任务，不自动续跑 |

探索实现采用可配置低角速度和短时长的小幅动作，之后停车等待；不引入反复大范围扫描。该幅度和返回超时属于待现场标定的实现参数，不声称为已测得的机械行程。

串口断链时，上位机只能停止自身输出并报告结果未知，不能声称已让正在执行的固定程序急停。v0.5规定固定程序在X5断链时继续完成，遥控接管或断联才按下位机规则中止。

## 6. 数据记录和完成条件

- 本批输入分别保留物料颜色顺序与目标圆环顺序，不用网页例子中的213、231硬编码执行。
- 每件记录圆环编号、物料编号、本批顺序索引、实际伸出长度mm、机构连续角rad，以及便于核对的记录时间。
- 记录发生在本件放置触发前；固定动作成功完成后才确认对应PLACE步骤。失败记录不能被当作已放置成功。
- 每次取回成功完成才确认对应PICK步骤。本批结果仍有三条PLACE和三条PICK，顺序与任务一致。
- P0仅作高位2号环校准后的底盘位置观测，不保存为本批返程目标；不记录底盘目标yaw。
- 新批次、复位或新任务清空旧机构位置表；停止后不从中间件自动恢复。
- 完成要求六条有序步骤、末次水平校准已达标或明确超时跳过、INIT完成、偏置移动到位停车、机构空闲及控制权释放。三件放完或三件取完都不能提前返回完成。
- 检查现有 `reference_restored` 在mission中的消费逻辑，按新版“标准高位参考恢复及末次视觉校准”的含义同步说明；它不能继续暗示已执行P0二维返回。超时跳过不得伪报视觉校准成功。

## 8. 参数计划

动作号按v0.5使用正式映射。控制参数填小的非空初值，网页提供编辑保存；以下是调试起点，不是实车标定结果。

| 参数组 | 拟用初值及用途 |
|---|---|
| arm | WORK=3、PLACE=8、PICK=5、INIT=2；不配置或发送额外下降 |
| vision | 共同准心为空则原图中心；图像有效期0.5秒 |
| angle_alignment | 上限3秒、目标斜率0、容差0.02、确认3帧；最大0.08rad/s，P=0.3 |
| base_servo | 误差8px、确认3帧、最大vx/vy各0.03m/s、停车阈值0.01m/s；u/v P各0.0003 |
| gantry_servo | 误差8px、固定4帧；最大旋转0.04rad/s、伸缩2RPM；小输出阈值0.005rad/s及0.2RPM；u P=0.0003、v P=0.02 |
| ring_search | 探索角速度幅值0.02rad/s、持续0.5秒 |
| gantry_return | 长度容差1mm、角度容差0.01rad；最大旋转0.04rad/s、伸缩2RPM；长度P=0.2、角度P=0.5；返回超时30秒 |
| execution | 连续控制50Hz、停止交接0.1秒、反馈有效期0.2秒；沿用现有动作受理与执行超时机制 |

各PID的I/D初值为0。底盘初始对准、机构视觉对准、机构反馈返回分开配置增益与限幅，不复用不同单位的PID。正式与调试配置保持独立，粗加工不改写原料、暂存控制参数。

## 10. 验证和验收标准

### 10.1 无硬件的软件验证

- 从真实控制类推进完整状态机，验证工作位对准2号环后直接进入机构对准，每件放置前均没有额外定时下降。
- 使用213和另一排列验证输入决定六步顺序，不硬编码；两批机构记录相互独立。
- 重复帧不累计，像素达标而两轴输出较大时不放料；四张新帧同时达标才触发。
- 放置前记录实际位置；将固定动作完成反馈改成高位位置，记录仍保持放置前值。
- 取回在没有任何物料视觉观测时仍可完成，目标来自对应记录；连续角跨π时不错误取最短圈。
- 初始2号环校准后，底盘平移输出保持0；末次只允许斜率纠偏角速度，无P0返程。
- 首末纠偏均3秒上限，超时走后续步骤且结果明确为跳过。
- 目标丢失停止、探索方向正确且幅度受控、重新可见后恢复；反馈或图像流断开则报错。
- 覆盖视觉JOG、反馈返回期间取消，以及固定动作拒绝/错误，检查无残留速度。
- 网页每批有六次1秒模拟，不发送8/5；每次模拟后真实WORK完成才推进，最终真实INIT完成后还需偏置移动到位并停车才结束。
- 使用真实ROS节点与PTY软件控制板验证机构反馈和命令交接，核对正式固定动作序列：`3,8,8,8,5,5,5,3,2`；只有必要的连续旋转/伸缩JOG，检查ud_rpm为0且没有额外定时下降。
- 回归原料、暂存、桥接和mission结果检查；原料/暂存按v0.5动作编号测试，不改变其流程。

测试调用真实实现，不复制状态机到测试。离线、PTY通过仅证明软件行为，不证明实车轨迹、夹取成功或机构精度。

### 10.2 实车调试顺序

1. 核对实际固件动作号、JOG后直接执行固定动作的支持，以及真实位置反馈和单位。
2. 低速核对左右转、伸缩、升降方向，高位/收拢姿态与取放后回高位行为。
3. 标定共同准心，验证工作位底盘对准2号环及机构对准使用同一准心的效果。
4. 单环验证工作位直接对准、四帧门槛和放置前位置记录，再验证高位反馈返回及固定取料高度。
5. 网页按两种顺序完成三放三取模拟，核对每次实际返回长度/角度及末次纠偏、收拢。
6. 接入正式取放，验收比赛两批任务、停止及故障处理；保存日志和实际参数。

计划阶段明确流程、协议映射、参数、正式/网页差异和验证要求；后续软件验收结果见实施记录。本次未连接真实相机、串口或车辆，实车动作仍需现场联调。

## 收纳后相机/车体中心偏置补偿

相机对准2号环时车体中心偏向3号环。按用户指定方向，收拢完成后沿车体正vx移动，不把图像方向或世界坐标x作为运动方向。距离唯一配置为 `agv_mission/config/mission.yaml` 中的 `mission_node.ros__parameters.camera_car_offset: 79.45`，单位mm；0禁用。mission在阶段6和12通过 `RunWorkBatch.camera_car_offset` 下发。8086每次开始粗加工时读取同一YAML，速度/容差等由粗加工 `exit_motion` 配置。

起点取收拢完成后的新鲜底盘里程，沿当时车头方向投影累计位移，仅输出正vx、vy/wz为0。默认限速0.03m/s、比例增益1、容差1mm、故障时限15s。里程到位后停止，收到新鲜低速反馈并满足停止等待才报告本批完成；超时或反馈异常沿用故障停车。逐件取放的机构记录、视觉准心和两次斜率纠偏不变。
