## 2. 依据与来源边界

今年规则依据：[命题与运行](/root/工创/1778571778700.pdf)第 4—8 页、[评分与规则](</root/工创/1778571778823 (1).pdf>)第 2—3 页。去年资料实际位于 `/root/去年开源`，与本工作区同属 `/root` 下的目录。

本次主要阅读三套工程的视觉程序、对应任务流程和必要的控制代码。未执行旧程序，因为它们在导入或启动时可能直接打开串口、相机并控制机构。以下“原代码行为”以源码为依据，不代表已复现实车性能。

目录中另有 `2027智能搬运视觉阶段方案表.md` 等后来整理的方案。这些是分析文档，不是去年算法实现；其中使用 RK3576、随龙门移动的相机等前提，与当前 X5、固定主相机和底盘伺服不同，不作为本项目既定方案。

在本次检查的三套 Python 视觉代码中未发现 YOLO、ONNX 或 Torch 推理路径。本文的深度学习建议属于后续设计，不能写成“去年开源已验证”。

## 3. 三套开源具体做了什么

### 3.1 西安理工塔吊方案：HSV 物料定位、三个目标辅助定位

源文件：[TransportCAR_OSS_1.0.py](/root/去年开源/Logistics_Vehicle_F407_V2/2025智能物流搬运_视觉_XAUT_20250815/TransportCAR_OSS_1.0.py)。

| 环节 | 原代码方法 | 本项目判断 |
|---|---|---|
| 物料定位 | `color_blocks_position_WL()`：高斯模糊 → HSV → 腐蚀 → 指定色阈值 → 外轮廓 → 最大轮廓面积筛选 → `minAreaRect` 中心 | 借鉴颜色分割与几何中心；改成二值掩膜上的形态学处理和多候选筛选 |
| 转盘整体观察 | `unit==1`：红绿蓝三个物料中心取平均，再用二维卡尔曼平滑 | 可辅助观察视野；不能作为随机摆放原料区的地图原点，也不作为抓取顺序依据 |
| 单物料定位 | `unit==2`：按下位机指定颜色输出滤波后中心 | 借鉴按任务选颜色；扩展今年六色编号 |
| 圆环定位 | `color_circle_position()`：图像形态学处理 → 灰度 → 梯度、增强、二值化 → `HOUGH_GRADIENT_ALT`；恰好检测到三个圆才按 x 排序 | 借鉴三工位排序；今年须增加同心圆归并、编号映射和部分遮挡处理 |
| 工位朝向参考 | `unit==3`：输出中间圆心和左右圆心 y 差 | 有助于观察工位方向；不能直接把像素差当角度，也不能用单圆心证明车身方向正确 |
| 第二轮码垛 | `unit==4`：检测蓝绿红物料中心，输出中间物料位置和左右 y 差 | 借鉴以底层物料替代被遮挡圆环作参考；改为当前同颜色物料逐项对准 |
| 决赛颜色顺序 | `unit==8`、`Judgeorder()`：按三色物料 x 顺序编码 | 不能取代今年任务码规定的搬运顺序 |

注意两个源码细节：`minAreaRect` 中心不是轮廓质心；函数中虽计算了 CLAHE 图像，后续梯度输入仍为 `gray_img`，所以不能声称该检测主链已经使用 CLAHE 输出。其二维卡尔曼状态为位置、转移矩阵为单位阵，主要是平滑，不是转盘速度预测。

### 3.2 江苏省冠方案：圆形候选、颜色占比、多帧确认

源文件：[zongchengxu20250724chusai.py](/root/去年开源/gcs-gold-medal/cv2_python/zongchengxu20250724chusai.py)。

| 环节 | 原代码方法 | 本项目判断 |
|---|---|---|
| 转盘物料定位 | `run_wukuaiyuanxin_1/2()`：固定 ROI → 灰度模糊 → 标准霍夫圆 → 圆内三色掩膜面积比较 → 位置稳定与颜色投票 | 借鉴局部几何复核和多帧确认；本项目先用 HSV 找物料，圆检测作为可选精定位 |
| 指定色停稳 | `run_wukuaiyuanxin_xuanzequyu()`：按固定区域找圆、匹配颜色，累计中心位移较小的次数 | 借鉴指定目标判稳；丢失目标时必须清计数，且底盘必须先停稳 |
| 三位置快速判色 | `run_wukuaiyuanxin_A()`：两个固定 ROI 统计红绿蓝面积，第三色排除推断；`LOOP1/2()` 等组合位置序列 | 不作为首版：当前目标色可直接检测；旧程序依赖三色位置与旋转假设，不适合照搬 |
| 圆环粗定位 | `run_sehuanyuanxin2()`：640×480 霍夫圆，圆周边区域判色，历史位置与颜色统计 | 借鉴粗定位与确认思路；今年用位置身份选择圆环 |
| 圆环精定位 | `run_sehuanyuanxin2_centered()`：切换 1920×1080、限定中央区域及半径，再做霍夫圆与稳定确认 | 借鉴粗到细的检测范围；首版固定分辨率，避免运行中切换成像条件 |
| 码垛定位 | `run_maduoyuanxin2()`、`..._centered()`：较小半径找物料顶面，颜色与位置确认 | 借鉴在底层物料上找中心；半径与 ROI 重新按当前相机确定 |
| 边界角度 | `detect_boundary_line()`：Canny → 霍夫线段 → 长度加权角度 → 多次方差检查 | 仅作备选方向参考；串口 `d` 分支中实际调用被注释，没有运行该纠偏函数 |

有函数并不等于主流程启用：串口 `0` 分支实际仍调用 `run_maduoyuanxin2()`，不是名称中带 `centered` 的版本。不要仅凭函数名把码垛解释成已经完整启用两阶段精定位。

不照搬的行为：部分分支无目标时保留稳定计数；一些判色分支无绝对面积门槛；超时后可能输出未充分确认的候选。新方案明确返回有效性、清理历史，不用候选结果冒充对准成功。

### 3.3 2025GongChuang_AGV：任务状态机、轮廓质心、机械臂伺服

主要来源：[video_processor.py](/root/去年开源/2025GongChuang_AGV/程序/上位机/国赛初赛/video_processor.py)、[task.py](/root/去年开源/2025GongChuang_AGV/程序/上位机/国赛初赛/task.py)、[positional_PID.py](/root/去年开源/2025GongChuang_AGV/程序/上位机/国赛初赛/positional_PID.py)。同时检查了决赛版本相关检测与任务代码；本项目参考初赛任务即可。

| 环节 | 原代码方法 | 本项目判断 |
|---|---|---|
| 物料检测 | `process_main_frame()`、`detect_material()`：HSV → 开闭运算 → 最大外轮廓 → 图像矩质心 | 推荐作为今日物料检测基线，补充 ROI、身份、形状和新鲜度检查 |
| 色环检测 | `detect_color_circle()`：ALT 霍夫圆 → 同心圆处理 → 方形 ROI 内目标色面积 → 候选中选 y 最大者 | 借鉴几何候选与身份分离；今年改为编号选择，不照搬 y 最大策略 |
| 坐标处理 | 相对可调准心计算误差，并按机械臂角度旋转 | 借鉴可调准心；固定相机的底盘坐标映射重新确定，不使用机械臂角度公式 |
| 视觉伺服 | `PID_Task()`：按误差距离分段选择 PID，将总速度沿误差方向分解给机械臂 | 借鉴远近分段思想；底盘首版用矩阵映射的限幅 P 控制 |
| 原料取料 | `subTaskNum==1_0`：跟踪目标色，同时配合机械臂高度、伸出量等条件抓取 | 不照搬动态跟抓；本项目按今年停留转盘先确认停稳 |
| 粗加工 | `subTaskNum==2_0`：依次对准放料，记录机械臂 XY，全部放完后回到记录的 XY 取回 | 借鉴先全放再全取；取回时重新检测物料，不把旧像素当机械臂坐标 |
| 暂存平放、码垛 | `3_1` 平放；`3_2` 带视觉精定位码垛；另有 `3_3` 不带精定位路径 | 借鉴模式划分；本项目采用逐项目标对准，不采用直接开环码垛 |

源码中的同心圆合并比较圆心坐标完全相等，实际霍夫结果有抖动，应改为距离门限。`handle_no_detection()` 最多保留旧坐标 1 秒，随后把误差写为零：本项目不采用，否则“无目标”可能被误判为“已对准”。旧任务的连续计数也需要改成只累计新的采集帧。

## 4. 各环节最终推荐

| 环节 | 今日首选 | 可选改进 | 首版不采用 |
|---|---|---|---|
| 原料检测 | 指定色 HSV、轮廓、质心、多候选约束 | 局部顶面圆心精定位；未来模型候选 | 全图最大色块无条件获胜 |
| 原料停稳 | 底盘静止时，同一目标的真实新帧位移与时间窗口检查 | 多物料一致性复核 | 用跟随后的图像静止判断转盘停转 |
| 粗加工放料 | 灰度霍夫圆、同心归并、三工位编号映射 | 已知工位结构辅助重关联 | 以红绿蓝颜色决定位置编号 |
| 粗加工取回 | 当前颜色 HSV 物料重新定位 | 已确认放置位置辅助筛选 | 直接复用放置时像素坐标 |
| 首批暂存 | 复用编号圆环算法，单独工位配置 | 放置后可见性检查 | 直接复用粗加工全部标定 |
| 第二批码垛 | 同色第一层物料HSV候选、质心基线与独立准心 | 优先评估局部霍夫顶面圆；未来分割/关键点模型 | 用第四组任务码作为码垛位置 |
| 伺服 | 每模式独立准心与增益、限幅 P、归零交接 | 远近分段 P；确有问题后再增加 PID/滤波 | 照搬旧机械臂 PID 数值 |

独立对准测试可以先覆盖一个物料/工位，再覆盖全部位置和两批数据。真实抓放、入仓、码垛动作确认与回中仍是后续接入项；当前 `aligned` 只表示该次视觉对准完成。
