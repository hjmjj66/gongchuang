# 上位机通信协议 v2.0 接入记录

日期：2026-11-17。依据：[上位机通信协议v2.0.md](../../上位机通信协议v2.0.md)，正文标注版本为v0.8。

粗加工放置与暂存第一层放置统一使用`cmd=6 PLACE_TEMP_1`，由动作启动时记录的机构位姿决定放置位置。暂存第二层继续使用`cmd=7 PLACE_TEMP_2`。`cmd=8 PLACE_ROUGH`已删除，新固件收到8会返回ACK result=4。

正式`coarse.yaml`与8086调试`debug.yaml`的`coarse.arm.place_cmd`均从8改为6。正式粗加工、8086真实取放、追踪模式手动放料、8087比赛调试都读取这两份配置；模拟分支继续按原有流程执行。粗加工仍在视觉对准并停稳后记录实际位置，再发送放料动作；取回顺序与实际位置反馈闭环沿用现有实现。

`ArmCommand.srv`删除`PLACE_ROUGH=8`常量，保留`PLACE_TEMP_1=6`。发包入口仅接受0～7；三区域工作动作配置仅接受2～7，网页动作号编辑上限同步为7。旧配置中的8会在配置入口被拒绝，避免发送已删除的动作。自行指定的外部配置须将粗加工`arm.place_cmd`同步改为6。

原料夹取4、粗加工夹取5、WORK=3、INIT=2保持现有映射。协议帧结构、STATUS脉冲反馈、ACK和动作完成判定沿用现有实现。

升级构建：

```bash
source /opt/ros/humble/setup.bash
cd /root/工创/ros2_ws
colcon build --symlink-install --packages-select agv_interfaces agv_cboard agv_perception
source /root/工创/ros2_ws/install/setup.bash
```

构建后重启桥接、视觉宿主及8086/8087相关进程，再开始新任务；运行中的进程不会自动切换已加载的动作号。安装目录的配置由构建生成，不直接修改生成文件。
