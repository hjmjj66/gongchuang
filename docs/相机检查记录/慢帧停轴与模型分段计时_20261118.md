# 慢帧停轴与模型分段计时

本次截图真实采集30.1FPS、识别10.4FPS、结果年龄0.503秒，最后一次YOLO总计388.9毫秒，几何4.0毫秒、进程交接24.1毫秒。相机仍在正常采集，不能把0.503秒的结果直接称为采集断流。

修复：超过max_frame_age_s（0.5秒）的结果仍立即停轴、清理跟随和达标计数，但不立即结束整场；及时新帧恢复后继续；按用户最新要求，无有效图像时一直停轴等待，不再因等待时长结束任务。正式比赛、8086和8087整批作业共用此判断。模型加载阶段用空白图预热实际检测链，提前执行运行库后处理初始化。

使用实际X5原六色INT8 BIN、1280×720本地静态图分段计时15次，未打开相机或串口。排除前三次后均值：预处理6.63毫秒、BPU调用11.12毫秒、后处理11.08毫秒、总计28.84毫秒。第一次后处理258.96毫秒，总计282.58毫秒。已确认初始化存在显著延迟；该静态图测量不能单独证明现场388.9毫秒的全部耗时来源，也不能证明后续调度抖动已消除。详细数据在log/shared_vision_20261118/model_latency_breakdown.json。

追加自查：正式区域执行器所有区域均等待机构停轴空闲后才提交固定动作，与整场调试保持一致；等待超过 arm_request_timeout_s 时报告停轴交接超时。正式流程反馈异常现在携带 C 板故障、机构状态与原因、三路反馈年龄及坐标绑定。修正视觉门禁测试使用当前有效的 WAIT_REQUIRED 状态。5 项视觉门禁检查通过；当前原料区两批完整抓取 ROS＋PTY 集成在修改前、修改后均通过，修改后日志为 log/shared_vision_20261118/raw_self_audit_final.log；agv_perception 重新构建成功。此验证使用串口与视觉仿真，尚未代表现场相机和实车整场验收。

仅运行5项针对性首帧/慢帧恢复/持续断流检查并构建，不重跑大批联测。实际服务需重启加载；截至检查时8087端口已关闭，未自动开始比赛。

用户追加要求：删除共享视觉门禁、原料区及暂存区内部的图像等待超时终止分支；过期/缺失图像只停轴等待，图像恢复后继续。硬件故障、动作拒绝、人工停止等处理保留。
